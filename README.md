# mints · Vision Notes

한국어 CV 학습 블로그 파일럿. Jekyll + GitHub Pages.

- 사이트: https://mints-s.github.io/CV-study-blog/
- 파일럿 원고: [_posts/2026-11-16-camera-calibration.md](_posts/2026-11-16-camera-calibration.md)
- 화면: 홈, 학습 순서, 읽는 방법, 글 목차와 수식, 투영 실습
- 새 글: `_posts/YYYY-MM-DD-slug.md`에 Markdown 추가
- 논문 템플릿: [templates/paper-review.md](templates/paper-review.md)

## 최초 게시 설정

저장소 Settings → Pages → Build and deployment에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 선택하고 Save. GitHub 기본 Jekyll 빌드가 이 소스를 게시한다. 별도 토큰·유료 서비스가 필요하지 않다.

## 운영

반복 글 생성 일정은 아직 설정하지 않았다. 글 커밋 후 Pages가 갱신된다. 날짜는 Asia/Seoul 기준이다. 수식 렌더링은 버전 고정된 MathJax CDN을 사용하므로 인터넷 연결이 필요하다. 도식과 실습은 직접 작성한 설명용이며 실측 결과가 아니다.
