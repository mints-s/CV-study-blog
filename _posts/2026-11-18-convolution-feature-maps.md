> **1분 요약**
>
> Convolution 층은 작은 영역을 보고, 같은 가중치를 여러 위치에서 반복 사용한다. 각 위치에서 얻은 반응을 공간적으로 배열한 것이 feature map이다. 일반적인 합성곱은 입력 채널들의 기여를 합해 출력 채널 하나를 만든다. Stride는 샘플링 간격, padding은 경계 처리, dilation은 커널 원소 사이 간격을 정한다.
>
> **기억할 문장:** 같은 필터를 공유한다는 것은 같은 패턴을 여러 위치에서 검사한다는 뜻이지, 입력이 이동해도 출력이 항상 같다는 뜻은 아니다.

## 1. 전체 내용: 학습하는 계수를 이미지에 배치한다

[Day 2]({{ '/notes/loss-gradient-backprop/' | relative_url }})에서는 손실의 기울기로 가중치를 바꾸었다. 오늘은 이미지에서 그 가중치를 어떻게 연결하는지 다룬다. 모든 출력이 이미지 전체를 보게 할 수도 있지만, 가까운 픽셀의 관계부터 처리하는 구조를 선택할 수 있다. Convolution은 **국소 연결**과 **공간적 가중치 공유**를 결합한다. 한 필터를 움직이며 얻은 값을 모으면 한 장의 반응 지도가 되고, 여러 필터를 사용하면 여러 출력 채널이 생긴다. 필터 값은 학습할 수 있으며, 작은 행렬로 직접 계산해 연산을 이해할 수 있다.

이 글의 수치와 도식은 직접 만든 예제다. 구조 설명은 Stanford CS231n 강의 자료 [1], 연산과 텐서 규약은 PyTorch 공식 문서 [2]를 확인했다. 논문 성능 재현이나 학습된 특징의 시각화는 아니다.

## 2. 핵심 아이디어: 국소 연결과 공유를 구별한다

국소 연결은 출력 한 점이 입력의 제한된 영역만 보는 것이다. 가중치 공유는 다른 위치에서도 같은 계수를 쓰는 것이다. 둘은 별도 선택이다. 작은 영역만 보되 위치마다 서로 다른 필터를 두는 모델도 생각할 수 있다.

예를 들어 RGB 입력의 각 위치에서 $3\times3$ 패치를 보고 출력 채널 8개를 만든다고 하자. 그룹을 나누지 않는 일반 합성곱에서 가중치 수는 $8\cdot3\cdot3\cdot3=216$개다. 출력 채널별 편향 8개를 더하면 **224개**다. 공간 위치가 많아져도 공유하는 계수 수는 그대로다.

반대로 $28\times28$개 위치마다 독립된 필터·편향을 사용하면 같은 국소 연결에서도 $28\cdot28\cdot224=175{,}616$개가 필요하다. 이는 파라미터 수의 비교이며 실행 시간이나 성능의 실측 비교는 아니다. 합성곱도 출력 위치가 늘면 연산량과 활성값 저장량은 증가한다.

**[해석]** “작은 필터라서 효율적이다”에 더해 “그 필터를 여러 위치에서 재사용한다”는 점을 함께 읽어야 한다. 다만 모든 위치에서 같은 규칙이 유리하다는 가정이 언제나 과제에 적합한 것은 아니다.

## 3. 한 점을 계산하면 feature map이 보인다

입력과 커널을 다음처럼 둔다. 채널은 각각 1개, 편향은 0, stride는 1, padding은 0, dilation은 1이다. 행은 아래로, 열은 오른쪽으로 증가하며 인덱스는 0부터 센다.

$$
X=\begin{bmatrix}
1&2&0&1\\
0&1&3&2\\
2&1&0&1\\
1&0&2&3
\end{bmatrix},
\qquad
K=\begin{bmatrix}1&0\\0&-1\end{bmatrix}
$$

첫 패치와 커널의 같은 위치끼리 곱한 뒤 더한다.

$$
Y_{0,0}=1(1)+2(0)+0(0)+1(-1)=0
$$

한 칸 오른쪽 패치에서는 $Y_{0,1}=2(1)+0(0)+1(0)+3(-1)=-1$이다. 같은 계산을 모든 유효 위치에 적용하면 다음과 같다.

$$
Y=\begin{bmatrix}
0&-1&-2\\
-1&1&2\\
2&-1&-3
\end{bmatrix}
$$

그림은 왼쪽의 작은 영역, 가운데 계수, 오른쪽 한 값을 순서대로 읽는다. **출력의 숫자는 클래스 확률이 아니다.** 이 커널에서는 패치의 왼쪽 위 값에서 오른쪽 아래 값을 뺀 차이다. 다른 커널이면 다른 반응을 얻는다.

딥러닝 라이브러리에서 convolution이라 부르는 연산은 보통 커널을 뒤집지 않는 cross-correlation이다. PyTorch Conv2d도 이를 명시한다. [2] 수학적 convolution처럼 커널을 두 축으로 뒤집으면 이 예제의 커널은 부호가 반대가 되어 출력도 반대 부호가 된다. 손으로 계산할 때 이 규약부터 맞춰야 한다.

## 4. 채널: RGB 세 장이 출력 세 장을 뜻하지 않는다

배치를 제외한 입력을 $X\in\mathbb R^{C_{\mathrm{in}}\times H\times W}$로 둔다. 일반 합성곱의 출력 채널 $o$는 입력 채널을 모두 합해 만든다. 다음 식은 stride 1, padding 0, dilation 1, groups 1인 경우다.

$$
Y_{o,i,j}=b_o+
\sum_{c=0}^{C_{\mathrm{in}}-1}
\sum_{u=0}^{k_h-1}
\sum_{v=0}^{k_w-1}
K_{o,c,u,v}X_{c,i+u,j+v}
$$

| 기호 | 의미 |
| --- | --- |
| $o,c$ | 출력·입력 채널 인덱스 |
| $i,j$ | 출력 행·열 |
| $u,v$ | 커널 안의 행·열 |
| $K$ | 크기가 $C_{\mathrm{out}}\times C_{\mathrm{in}}\times k_h\times k_w$인 가중치 |
| $b_o$ | 출력 채널마다 하나인 편향 |

RGB 패치라면 출력 채널 하나의 필터에도 R·G·B에 대응하는 계수가 모두 있다. 각 입력 채널의 내적을 합하고 편향은 한 번 더한다. 따라서 입력 채널 3개에서 출력 채널 8개를 만드는 것은 자연스럽다. 깊은 층의 채널은 일반적으로 RGB 색상 채널이 아니다.

PyTorch의 배치 입력 규약은 $N,C,H,W$다. groups를 사용하면 채널 연결이 달라지므로 위 가중치 크기와 합산 범위를 그대로 적용하면 안 된다. [2] 이 글은 groups 1만 계산한다.

Feature map이라는 용어는 문맥에 따라 한 출력 채널 또는 채널들을 묶은 텐서를 가리킨다. 여기서는 $Y_{o,:,:}$ 한 장을 한 채널의 feature map이라 부른다. Conv의 원시 출력인지 활성화 이후인지도 구분한다. 예를 들어 ReLU를 적용하면 $\max(0,Y)$가 되어 위 예제의 음수는 0으로 바뀐다. Conv2d 자체가 ReLU를 자동 적용하는 것은 아니다.

## 5. 출력 크기: 어디에 필터를 놓을 수 있는가

높이 방향의 출력 크기는 다음과 같다. $p$는 위아래 각각의 대칭 padding, $s$는 stride, $d$는 dilation이다. 너비에도 같은 방식으로 적용한다. [2]

$$
H_{\mathrm{out}}=
\left\lfloor
\frac{H+2p-d(k_h-1)-1}{s}
\right\rfloor+1
$$

직관적으로 커널이 차지하는 유효 폭은 $d(k_h-1)+1$이다. 이를 padded 입력 안에 놓을 수 있는 시작점 개수를 세는 식이다.

아래는 앞의 $4\times4$ 입력과 $2\times2$ 커널에서 한 조건씩 바꾼 결과다. 나머지 조건은 표에 모두 명시했다.

| stride | zero padding | dilation | 출력 크기 | 확인할 점 |
| --- | --- | --- | --- | --- |
| 1 | 0 | 1 | $3\times3$ | 원래 예제 |
| 2 | 0 | 1 | $2\times2$ | 시작 위치를 두 칸씩 건너뜀 |
| 1 | 1 | 1 | $5\times5$ | 테두리에 0을 추가 |
| 1 | 0 | 2 | $2\times2$ | 커널 원소 사이 간격이 2 |

Stride 2의 값은 $\begin{bmatrix}0&-2\\2&-3\end{bmatrix}$다. Stride 1 출력의 행·열 인덱스 0, 2를 선택한 것과 같다. Dilation 2는 $\begin{bmatrix}1&1\\-2&-2\end{bmatrix}$다. 첫 값은 입력 $(0,0)$과 $(2,2)$를 사용해 $1-0=1$이 된다.

Padding은 크기만 바꾸는 옵션이 아니다. 경계 밖에 어떤 값을 가정하느냐가 테두리의 반응을 바꾼다. “same”이라는 이름만으로 모든 라이브러리의 stride·비대칭 padding 규칙이 같다고 가정하지 않는다.

## 6. 검증 코드와 수용 영역

<details markdown="1">
<summary>실행한 단일 채널 검증 코드</summary>

~~~python
X = [[1, 2, 0, 1], [0, 1, 3, 2],
     [2, 1, 0, 1], [1, 0, 2, 3]]
K = [[1, 0], [0, -1]]

def corr(x, k, stride=1, pad=0, dilation=1):
    h, w = len(x), len(x[0])
    kh, kw = len(k), len(k[0])
    a = [[0] * (w + 2 * pad) for _ in range(h + 2 * pad)]
    for i in range(h):
        for j in range(w):
            a[i + pad][j + pad] = x[i][j]
    oh = (h + 2 * pad - dilation * (kh - 1) - 1) // stride + 1
    ow = (w + 2 * pad - dilation * (kw - 1) - 1) // stride + 1
    return [[sum(k[u][v] * a[i * stride + u * dilation]
                              [j * stride + v * dilation]
                 for u in range(kh) for v in range(kw))
             for j in range(ow)] for i in range(oh)]

assert corr(X, K) == [[0, -1, -2], [-1, 1, 2], [2, -1, -3]]
assert corr(X, K, stride=2) == [[0, -2], [2, -3]]
assert corr(X, K, dilation=2) == [[1, 1], [-2, -2]]
padded = corr(X, K, pad=1)
assert len(padded) == 5 and all(len(row) == 5 for row in padded)
assert 8 * (3 * 3 * 3 + 1) == 224
assert 28 * 28 * 224 == 175616
~~~

Python 정수 연산으로 출력 행렬·크기·파라미터 수를 검증했다. PyTorch 실행 결과나 학습 성능을 검증한 것은 아니다.

</details>

수용 영역(receptive field)은 한 출력 위치에 영향을 줄 수 있는 입력 영역이다. 예를 들어 stride 1, dilation 1인 $3\times3$ 층 두 개를 쌓으면 내부 출력 위치가 볼 수 있는 원본 입력 범위는 $5\times5$다. 두 번째 층의 3칸이 각각 첫 번째 층의 3칸을 보므로 합쳐지는 범위가 5칸이 된다. 세 층이면 7칸이다.

이것은 **이론적으로 영향을 줄 수 있는 범위**다. 학습한 가중치·활성화에 따라 실제 영향의 크기는 균등하지 않다. 두 층 사이에 비선형 활성화를 넣은 모델은 단순히 큰 선형 필터 하나와 같지도 않다. [해석] 논문에서 큰 문맥을 본다는 주장을 읽을 때는 수용 영역의 크기와 실제 정보 활용을 별도로 확인한다.

## 7. 이동 등변성과 불변성은 다르다

입력의 패턴이 이동할 때 출력의 반응도 같은 만큼 이동하는 성질이 **이동 등변성**이다. 이동해도 출력이 그대로인 **이동 불변성**과 다르다.

공유 필터를 stride 1로 적용하고 경계 영향을 제외하면, 같은 패치는 옮겨진 위치에서도 같은 반응을 만든다. 이를 $F(TX)=T(F(X))$로 쓸 수 있다. $T$는 격자 위 정수 이동이다. 유한 이미지의 crop·padding과 stride에 따른 샘플링은 이 조건을 바꾼다.

**[직접 구성한 반례]** $5\times5$의 0 배열에서 위치 $(2,2)$만 1로 둔다. $1\times1$ 항등 커널에 stride 2를 사용하면 행·열 0, 2, 4만 읽으므로 출력에 1이 나타난다. 입력의 1을 오른쪽 한 칸인 $(2,3)$으로 옮기면 모든 출력이 0이다. 입력 이동을 출력의 단순 이동으로 설명할 수 없다. 아래 코드로 확인했다.

~~~python
a = [[0] * 5 for _ in range(5)]
b = [[0] * 5 for _ in range(5)]
a[2][2] = 1
b[2][3] = 1
assert sum(map(sum, corr(a, [[1]], stride=2))) == 1
assert sum(map(sum, corr(b, [[1]], stride=2))) == 0
~~~

이는 샘플링 위치에 대한 반례이며 실제 CNN의 분류 정확도 실험은 아니다.

| 흔한 오개념 | 구별할 기준 |
| --- | --- |
| 필터 하나는 입력 채널 하나만 본다 | 일반 합성곱은 입력 채널을 합산한다 |
| feature map은 물체 위치 확률이다 | 어떤 연산·손실로 만들어졌는지 확인한다 |
| 작은 필터는 항상 작은 문맥만 본다 | 층을 쌓으면 원본 입력 기준 수용 영역이 커진다 |
| 합성곱은 모든 이동에 불변이다 | 등변성의 조건과 경계·stride를 구별한다 |
| 채널이 많으면 해상도도 높다 | 채널 수와 공간 크기는 다른 축이다 |

## 8. 시사점과 확장 아이디어

**[해석]** CNN 논문은 출력 텐서의 크기만 읽어도 비교가 명확해진다. 채널 확대는 표현의 수를, stride는 공간 샘플링 밀도를 바꾼다. 작은 물체가 중요한 과제에서 계산량을 줄이려고 해상도를 낮추면 무엇을 잃는지 확인해야 한다. 이것은 특정 구조가 더 좋다는 결론이 아니라 비교할 조건을 찾는 방법이다.

**[아이디어 · 미검증]** 작은 물체의 검출 실패 중 일부가 물체 자체보다 stride 격자와의 정렬에 민감한 현상일까?

- **가설:** 동일한 작은 패턴을 한 픽셀씩 이동시킬 때 다운샘플링 모델의 반응이 위치에 따라 크게 달라질 수 있다.
- **비교:** 같은 학습 조건의 stride 1 모델, stride 2 모델, stride 2 전에 고정 저역통과 필터를 넣은 모델.
- **통제:** 같은 합성 패턴·배경·학습 데이터·시드 집합을 사용하고 경계에서 충분히 떨어진 위치만 평가한다. 연산량과 파라미터 수 차이는 따로 보고한다.
- **최소 실험:** 물체 크기별로 수평·수직 1픽셀 이동을 반복한다. 분류 또는 검출 중 과제를 하나로 고정한다.
- **지표:** 위치별 정확도와 최악 위치 성능, 이동 전후 점수 차이를 측정한다. 특징을 비교할 때는 좌표 정렬이 가능한 이동만 별도로 비교한다.
- **기각 기준:** 여러 시드에서 위치 민감도 차이가 재현되지 않거나 저역통과 처리의 이점이 정확도 하락으로 상쇄되면 제안을 수정한다.

위 아이디어는 실행하지 않았다. 앞의 항등 커널 반례만으로 학습된 검출기의 개선을 주장할 수는 없다.

## 9. 3분 복습

1. 입력 채널 3개, 출력 채널 8개, $3\times3$ 커널, groups 1, bias 포함인 층의 파라미터 수는 얼마인가?
2. $4\times4$ 입력에 $2\times2$ 커널, stride 2, padding 0, dilation 1이면 출력 크기는 무엇인가?
3. 이동 등변성과 이동 불변성은 어떻게 다른가?

<summary>답과 연결 설명</summary>

1. $8(3\cdot3\cdot3+1)=224$개다. 공간 위치마다 새 가중치를 추가하지 않는다.
2. $2\times2$다. 각 축의 시작 위치는 0과 2다.
3. 등변성은 입력이 이동하면 출력도 대응해 이동하는 성질이고, 불변성은 출력 자체가 유지되는 성질이다. 경계와 stride의 조건을 함께 확인한다.
