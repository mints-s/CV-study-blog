# CV 학습 게시 운영 규칙

## 작업 대상과 상태
- 저장소: mints-s/CV-study-blog, 기본 브랜치 main.
- 사용자 요청에 따라 새 학습 글 작성·수정·커밋·공개 게시까지 수행한다.
- 매 실행에서 최신 _data/study_plan.json, roadmap.html, templates/STYLE.md, 관련 템플릿과 기존 글을 먼저 읽는다.
- 한 번에 다음 미완료 회차 하나를 처리한다. 날짜 차이만으로 회차를 계산하지 않는다.
- published 상태와 실제 글을 함께 확인해 중복을 방지한다. 동시 실행·분기 충돌 시 최신 상태를 다시 읽고 완료된 항목을 재발행하지 않는다.
- Day 1은 2026-11-16에 게시했다. Day 5는 기존 camera-calibration 글을 보완하고 series_day: 5를 추가한다. 기존 URL을 보존한다.
- 첫 21회 완료 후에는 대표 연구 보강 → 후속 개선 → 분야 간 연결 순으로 다음 주제를 선정하고 목록에 day 22 이후 항목을 추가한다.

## 작성
- 본문은 한국어 해라체(~이다/~한다). 사용자 대화·진행 및 완료 보고만 존댓말이다.
- 기초: 1분 요약, 전체 내용, 핵심 아이디어·수식·기호·차원, 정확한 도식, 작은 수치 예제, 오개념·한계, 시사점, 검증 가능한 확장 아이디어, 복습 3문항과 답, 출처.
- 논문: 정식 제목·저자·연도·학회·원문 버전·원문/공식 코드 링크, 1분 요약, 전체 요약, 핵심 기여, 수식·파이프라인, 핵심 Figure 3–5개와 전체 목록, 비교 조건이 있는 실험·ablation, 한계·시사점, 확장 아이디어, 복습·다음 읽기.
- 본문은 약 8–12분, 상단 요약은 약 1분 읽기를 목표로 한다. 길고 어려운 유도는 details에 배치한다.
- 원문 주장·[해석]·[아이디어]를 구별한다. 아이디어에는 가설·비교 대상·통제·최소 실험·지표·기각 기준을 포함한다.
- 공식 문서·원 논문·부록·공식 코드 등 1차 출처를 실제로 열고 확인한다. 초록만으로 상세 리뷰를 작성하지 않는다.
- 그림 번호·페이지·버전·축·단위·조건을 확인한다. 필요한 그림은 원문에서 적법하게 인용하거나 재구성해 출처를 밝힌다. 정확한 수학 도식에 생성 이미지를 쓰지 않는다.
- 수치를 꾸며내지 않는다. 미확인은 표시하고 핵심 근거가 없으면 _drafts에 저장하며 회차를 완료 처리하지 않는다.
- 기존 글과 선수 지식·다음 질문을 연결한다. 기초가 부족하면 해당 글에 보충 설명을 넣거나 보충 글을 우선한다.

## 저장과 게시
- UTF-8로 보존한다. 새 글은 _posts/YYYY-MM-DD-slug.md, 그림은 assets/ 아래에 둔다. 한국 시간 날짜를 사용하며 미래 시각 front matter로 글이 숨겨지지 않도록 한다.
- front matter: layout: post, title, description, date(+09:00), category_label, series_day, topic, tags, reading_time. cover는 실제 존재하는 이미지일 때만 넣는다.
- 글·도식·상태 목록·앞뒤 링크를 같은 커밋에 반영한다. 공개 글에 빈 링크나 자리표시자를 남기지 않는다.
- 성공한 게시 항목은 status: published, url, published_date를 기록하고 next_day를 갱신한다.
- 본문 숫자 계산·한글 인코딩·내부 링크를 확인한다. GitHub Validate blog 및 pages build and deployment 결과를 확인한다. 실패하면 원인을 고친다.
- 커밋 성공과 배포 성공을 구별한다. 배포 상태가 미확인이면 사용자 보고에 정확히 명시한다.
- UI/레이아웃을 불필요하게 다시 만들지 않는다. 기존 사용자 변경과 URL을 보존한다.
- 실행 실패 후 다음 실행은 같은 미완료 항목에서 이어간다. 이미 글이 존재하면 새 글 대신 수정·검증한다.
- 자동 일정: 2026-11-17~2026-12-06 매일 05:00 KST(20회), 이후 2026-12-09부터 3일마다 05:00 KST. 05시는 작업 시작이며 공개 완료 시각 보장이 아니다.
- 사용자에게 회차·주제·핵심 내용·게시 링크·검증 결과 또는 구체적 차단 요인을 존댓말로 보고한다.
